# Bundled alarm sounds (Android)

The `.wav` files in this folder are generated by `scripts/generateSounds.js`
(synthesized tones - fully original, royalty-free by construction):

- `classic_beep.wav` / `gentle_rise.wav` / `synth_morning.wav` - user-selectable
  fallback alarm sounds, looped by `react-native-sound`
  (`src/services/audio/fallbackSound.ts`).
- `alarm_fallback.wav` - the notification channel sound
  (`src/services/alarms/schedulerShared.ts`).

To replace them with nicer produced audio, keep the same filenames (or update
both referencing files), and regenerate/copy the same set into
`ios/WakeTune/Sounds/` (already registered in the Xcode project).

Regenerate anytime with: `node scripts/generateSounds.js`
